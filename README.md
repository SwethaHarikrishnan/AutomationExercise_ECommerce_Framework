# AutomationExercise E-Commerce Automation Framework

## Project Overview
This project automates the core functionalities of the AutomationExercise E-Commerce application using Selenium WebDriver, Java, TestNG, Maven, and the Page Object Model (POM) design pattern.

The framework covers end-to-end business workflows including Registration, Login, Product Search, Cart Management, Checkout, Payment Processing, and Logout.

## Technology Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Git & GitHub
- Eclipse IDE

## Modules Automated
- User Registration
- User Login
- Product Search
- Add to Cart
- Checkout
- Payment
- User Logout

## Framework Features
- Page Object Model (POM) Architecture
- Reusable Utility Classes
- TestNG Test Execution
- Screenshot Capture
- Explicit Wait Implementation
- Configuration Management
- TestNG Reporting
- Maven Build Support
